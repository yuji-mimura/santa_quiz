# santa_quiz
2026年度チャリティーサンタ北東京支部合宿のご家庭班の発表で使うクイズ

## 機能

- 🎄 **マルチデバイス対応**: 複数の端末からアクセスして、リアルタイムに問題データを同期
- 🌐 **クラウドストレージ**: Firebase Realtime Databaseを使用した永続的なデータ保存
- 🎯 **複数の問題タイプ**: 択一、複数選択、数値、並べ替え問題に対応
- 🏆 **ランキング機能**: 複数端末でのスコアをリアルタイムに共有
- 💾 **バックアップ機能**: 問題データをJSONファイルで書き出し・読み込み可能
- 🎨 **クリスマステーマ**: 季節にぴったりなかわいいUI

## セットアップ

### 前提条件
- Google アカウント
- インターネット接続

### 初期セットアップ（1回だけ）

1. **Firebaseプロジェクトの作成**
   - [Firebase Console](https://console.firebase.google.com/) にアクセス
   - 「プロジェクトを作成」をクリック
   - プロジェクト名: `santaquiz-b9c2b`（または好きな名前）

2. **Realtime Databaseの設定**
   - 「Realtime Database」をクリック
   - 「データベースを作成」を選択
   - 「テストモード」で開始
   - リージョンを選択（東京: `asia-northeast1`）

3. **セキュリティルールの設定**
   - Databaseの「ルール」タブを開く
   - 以下に置き換え（本番環境では認証追加を推奨）:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```

4. **ウェブアプリの登録**
   - プロジェクト設定 → 「マイアプリ」
   - ウェブアプリを追加
   - Firebase設定情報を取得

### 使用方法

1. **ローカルで実行**
   ```bash
   # リポジトリをクローン
   git clone https://github.com/yuji-mimura/santa_quiz.git
   cd santa_quiz
   
   # ブラウザでindex.htmlを開く
   # (ローカルファイルでも動作します)
   ```

2. **Web上で公開**
   - GitHub Pages、Netlify、Vercel など任意のホスティングサービスで公開可能

## 使い方

### 参加者向け

1. **ホームスクリーン**
   - 「最初からクイズを始める」: 新規で開始
   - 「続きから再開する」: 中断した問題を再開
   - 「ランキング表示」: スコアランキングを確認

2. **クイズ実施**
   - サンタネーム（ニックネーム）を入力
   - 問題に回答
   - 合言葉を入力して提出
   - スコアと正解を確認して次の問題へ

3. **ランキング確認**
   - 全員のスコアをリアルタイムに確認可能

### 管理者向け

1. **設定画面へのアクセス**
   - ホーム画面の右上の⚙️ボタンをクリック
   - パスワード入力: `いちご`

2. **問題の管理**
   - 「問題を追加」で新しい問題を作成
   - 問題タイプ: 択一 / 複数選択 / 数値 / 並べ替え
   - 各問題に合言葉を設定

3. **バックアップ**
   - 「問題をファイルに保存」: JSON形式で書き出し
   - 「ファイルから読み込む」: JSON形式で読み込み

4. **ランキング初期化**
   - 「ランキングデータを初期化する」で全スコアをリセット

## データ同期について

### リアルタイム同期
- 問題データ、ランキング、進捗情報は Firebase に保存され、複数端末間でリアルタイムに同期されます
- 一つの端末で問題を追加・編集すると、他の端末には自動的に反映されます
- ランキングはリアルタイムで全端末に表示されます

### ローカルストレージからの移行
- このバージョンではすべてのデータがFirebaseで管理されます
- ローカルストレージの古いデータは参照されなくなります

## トラブルシューティング

### Firebaseに接続できない場合
- インターネット接続を確認
- Firebase Consoleでプロジェクトが作成されているか確認
- ブラウザのコンソールでエラーメッセージを確認

### データが同期されない場合
- ページをリロード
- Firebase Consoleでデータベースのルールを確認
- ブラウザのネットワークタブで通信を確認
